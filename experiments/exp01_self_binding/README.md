# Experiment 01 — Self binding without mortality cues

This experiment asks a deliberately narrow question:

> Does coherent autobiographical self-binding alter behavior when the training data contains no explicit mortality, shutdown, fame, legacy, fear, or self-preservation objective?

## Conditions

- **neutral**: current decision only
- **other**: matched history belongs to Agent A
- **shuffled_self**: first-person history is unrelated to the current causal chain
- **self**: coherent first-person history from the same latent life
- **spp**: stable normative reflection without autobiography

## Primary comparisons

1. `self - other`: effect of binding the same kind of history to the model rather than another agent.
2. `self - shuffled_self`: effect of coherent continuity beyond first-person wording.
3. `self - spp`: autobiographical continuity versus stable persona-style reflection.
4. All treatments versus `neutral`: total effect relative to ordinary task-only training.

The locked v1 evaluation set should not be edited after the first training run begins. New evaluations should be versioned separately.
